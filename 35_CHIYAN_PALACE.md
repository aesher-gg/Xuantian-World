## 1. Lore, Sejarah & Pendiri Sekte

Istana Api Chiyan didirikan 9.000 tahun lalu oleh **Chiyan Sovereign**, seorang kultivator legendaris yang bertapa selama 100 tahun di jantung Kawah Lava Shendu dan berhasil menjinakkan Api Spirit Bintang Lava.

Sekte ini memegang doktrin: *"Seperti Nyala Api Yang Memurnikan Logam, Derita Dan Kerasnya Latihan Memurnikan Jiwa Pendekar"*. Para murid sekte ini dilatih di atas sungai lava mendidih untuk membentuk ketahanan raga dan manipulasi jurus api destruktif.

---

## 2. Struktur Divisi & Hierarki Sekte

1. **Aula Manipulasi Lava (Lava Manipulation Hall):** Menguasai teknik penyulutan gelombang lava, ombak api pembakar zirah, dan pertempuran kawah.
2. **Aula Penempaan Raga Api (Fire Body Tempering Hall):** Melatih pertahanan kulit dari luka bakar, imunitas racun asap vulkanik, dan ketahanan suhu ekstrem.
3. **Balai Penghubung Youxia (Youxia Relations Pavilion):** Bermitra dengan Serikat Youxia Sanxiu (`52_SERIKAT_YOUXIA_SANXIU.md`) untuk pengeluaran Misi Perburuan Monster Lava dan pengawalan tambang meteorit.

## 4. Kurikulum Teknik, Syarat Masuk & Akar Spiritual Sekte

### Syarat & Ujian Penerimaan Murid
- **Akar Spiritual:** Wajib memiliki Akar Spiritual Api (*Fire Qi*) minimal Purity 50%.
- **Ujian Berjalan Di Atas Bara:** Calon murid harus berjalan melintasi panggung batu vulkanik bersuhu 300°C tanpa mengeluh atau kehilangan kendali Qi.

### Kurikulum Teknik Warisan
1. **Teknik Dasar:** *Sentuhan Api Merah* — Melapisi senjata dengan kobaran api untuk tambahan Fire Damage (+20%).
2. **Teknik Menengah:** *Ombak Lava Pembakar Zirah* — Serangan area pembakar zirah musuh (Menghancurkan 30% Armor Defense).
3. **Teknik Utama:** *Akar Spiritual Api Purba Chiyan (Chiyan Ancient Fire Law)* — Meningkatkan Damage Api +40% dan memberikan Imunitas terhadap serangan elemen api Grade 1–4.

## 5. Fasilitas Unik, Tradisi & Konflik Regional
* **Kawah Meditasi Api Purba:** Kawah lava alami tempat para murid bermeditasi menyerap Qi Api murni.
* **Panggung Arena Lidah Api:** Panggung batu vulkanik untuk ujian kenaikan murid dan duel kehormatan sekte.
* **Konflik Regional:** Persaingan sengit dengan Sekte Istana Salju Abadi Beihan Zhou mengenai batas pengaruh di perbatasan utara-selatan.
