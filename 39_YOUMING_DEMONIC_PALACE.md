## 1. Profil & Spesialisasi Sekte

Sekte Api Iblis Youming adalah sekte iblis terbesar penguasa Youming Zhou. Sekte ini mengajarkan *Hukum Bayangan & Api Hitam Purba*, berfokus pada manipulasi kegelapan, pembunuhan sunyi, penyerap energi jiwa lawan, dan serangan halusinasi bayangan.

## 3. Kurikulum Teknik & Hukum Sekte

1. **Teknik Dasar:** *Tebasan Bayangan Hitam* — Serangan cepat dari celah bayangan musuh.
2. **Teknik Menengah:** *Kobaran Api Hitam Menyerap Qi* — Membakar 15% Qi musuh dan mengonversinya menjadi pemulihan HP.
3. **Teknik Utama:** *Hukum Bayangan Youming (Youming Shadow Law)* — Meningkatkan Stealth +40%, Critical Hit Damage +35%, dan Evasion di area gelap +25%.

---

## 4. Fasilitas Unik Sekte
* **Gua Bayangan Abadi:** Gua pertapaan gelap total tanpa cahaya untuk mengasah kepekaan indra jiwa.
* **Panggung Duel Darah Youming:** Arena pertempuran bebas tanpa hukum untuk menguji ketangkasan bertarung murid.
