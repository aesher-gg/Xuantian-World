## 1. Profil & Spesialisasi Sekte
Sekte Alkimia terkemuka penguasa resep Pill Breakthrough Ningyuan, Lingyi, dan Xuantian di seluruh Xuantian World. Sekte ini menguasai penggunaan Kuali Alkimia Suhu Tinggi dan manipulasi Api Spirit Alami.

## 3. Kurikulum Teknik & Hukum Sekte

1. **Teknik Dasar:** *Ekstraksi Saripati Herbal* — Memurnikan tanaman obat dengan efisiensi +20%.
2. **Teknik Menengah:** *Pengendalian Api Danhuang* — Menstabilkan suhu kuali untuk mencegah ledakan obat.
3. **Teknik Utama:** *Resep Pill Breakthrough Danhuang* — Meracik *Ningyuan Pill*, *Lingyi Pill*, dan *Xuantian Pill* Grade High.

## 4. Fasilitas Unik Sekte
* **Kuali Danhuang Purba:** Kuali Alkimia Raksasa Grade 7 yang bertaut pada Urat Api Lava Kawah Shendu.
* **Perpustakaan Resep Purba:** Tempat penyimpanan ribuan gulungan resep obat penyembuh dan pill kultivasi.
