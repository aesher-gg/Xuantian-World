## 1. Lore, Sejarah Purba & Doktrin Utama

Sekte Alkimia Danhuang didirikan 8.000 tahun lalu pada pertengahan Era Kuno oleh **Leluhur Danhuang**, seorang Grandmaster Alkemis legendaris yang memecahkan rahasia penggabungan Api Spirit Alami Gunung Berapi Chiyan dengan bahan-bahan obat spiritual dari seluruh benua. Sebelum berdirinya Danhuang, tingkat kegagalan peracikan Pill Breakthrough mencapai 70% akibat ketidakstabilan suhu kuali. Leluhur Danhuang merancang Formasi Pengikat Api Urat Bumi yang menstabilkan energi panas alami kawah Shendu, memungkinkan pemurnian obat berkadar kebersihan (*Purity*) hingga 99%.

Doktrin Suci Sekte: *"Setiap Tetes Embun Herbal Adalah Nyawa Keabadian; Kuali Yang Bersih Menempa Jiwa Yang Murni"*.

Sekte Danhuang diakui secara mutlak sebagai otoritas alkimia dan pemurnian pill terbesar di Xuantian World. Sekte ini mengontrol sertifikasi kuali spirit, pengujian kadar racun obat (*pill toxins*), serta monopoli pendaftaran resep *Ningyuan Pill*, *Lingyi Pill*, dan *Xuantian Pill*. Setiap tahun, ribuan pembudidaya dari 10 Wilayah berbondong-bondong menuju Puncak Danhuang hanya demi membeli sebutir obat terobosan ranah buatan para tetua sekte.

## 2. Struktur Divisi, Hirarki & Dinamika Faksi Internal

### Divisions & Halls Utama
1. **Aula Kuali Utama (Main Cauldron Hall / 主鼎殿):** Pusat pemurnian Pill Breakthrough kelas tinggi (Grade 5–8) dan pengawasan Kuali Danhuang Purba.
2. **Aula Ekstraksi Herbal (Herbal Extraction Hall / 提草殿):** Memilahkan, mencuci, dan mengesktrak saripati obat dari Lembah Biyang (Shenmu Zhou) dan Gurun Xixuan dengan presisi mikroskopis.
3. **Aula Uji Purity & Toxins (Purity & Toxicity Testing Hall / 验丹殿):** Meneliti tingkat kebersihan dan kandungan racun pil (*pill toxins*) sesuai parameter `16_VITALITY_HUNGER_SYSTEM.md`.
4. **Aula Penjaga Api Urat Bumi (Earth Vein Fire Guard Hall / 地火守御殿):** Faksi militer sekte yang mengamankan saluran pipa lava dan saluran gas api spiritual dari sabotase monster atau faksi rival.
5. **Balai Pasokan Youxia (Youxia Supply Pavilion / 游侠供药阁):** Pintu kerja sama resmi dengan Serikat Youxia Sanxiu (`52_SERIKAT_YOUXIA_SANXIU.md`) untuk transaksi pil penyembuh massal dan penerbitan misi pengumpulan herbal langka.

### Dinamika Politik & Faksi Internal
- **Faksi Api Kemurnian (Purity Fire Faction):** Dipimpin oleh Tetua Yan Huo. Berfokus pada mengejar kebersihan pil (Purity 95%+) dan teknik tradisional tanpa bahan buatan. Menolak keras kompromi kualitas demi kuantitas produksi.
- **Faksi Pasokan Massal (Mass Supply Faction):** Dipimpin oleh Tetua Ling Dan. Mendorong peningkatan volume produksi pil breakthrough menengah untuk memenuhi permintaan pasar lelang Wanbao dan Serikat Youxia, meski Purity berada di kisaran 75–80%.

## 4. Kurikulum Teknik, Syarat Masuk & Jenjang Keanggotaan

### Syarat Penerimaan & Ujian Masuk
- **Syarat Akar Spiritual:** Wajib memiliki Akar Spiritual Elemen Api (*Fire Qi*) atau Kayu (*Wood Qi*) minimal Purity 50%.
- **Ujian Pengendalian Api (Fire Control Test):** Calon murid memegang kuali tembaga tanpa alas dan harus menjaga nyala Api Spirit alami pada suhu konstan selama 2 jam tanpa menghanguskan selembar daun obat uji.

### Jenjang Murid & Kemajuan Ranah
1. **Murid Luar (Outer Disciple):** Menyuci bahan obat, memotong akar herbal, dan menguasai *Ekstraksi Saripati Herbal*.
2. **Murid Dalam (Inner Disciple):** Memurnikan pil penyembuh dasar & pil energi Qi, serta menguasai *Pengendalian Api Danhuang Tiga Warna*.
3. **Murid Inti (Core Disciple):** Meracik *Ningyuan Pill* dan *Lingyi Pill* Grade High, serta mengakses kuali batu urat api.
4. **Murid Warisan (Legacy Disciple):** Diizinkan menggunakan Kuali Danhuang Purba dan mempelajari resep rahasia *Pill Penembus Faxiang*.

### Kurikulum Teknik Warisan
- **Teknik Dasar:** *Ekstraksi Saripati Herbal (Herbal Essence Extraction)* — Memurnikan sari tanaman obat dengan efisiensi +20% & hemat bahan baku.
- **Teknik Menengah:** *Pengendalian Api Danhuang Tiga Warna (Three-Color Danhuang Fire)* — Menstabilkan suhu kuali untuk mencegah ledakan obat (-50% Risk of Pill Failure).
- **Teknik Utama:** *Resep Breakthrough Danhuang (Danhuang Breakthrough Recipe)* — Meracik *Ningyuan Pill*, *Lingyi Pill*, dan *Xuantian Pill* Grade High dengan Purity minimal 85%.
- **Teknik Rahasia Puncak:** *Pembalikan Purifikasi Jiwa (Soul Purifying Alchemy)* — Meracik ramuan pembersih *pill toxins* yang mampu menghapus 100% racun akumulasi obat dari dantian pembudidaya.

## 5. Fasilitas Unik, Artefak & Sumber Daya Rahasia

* **Kuali Danhuang Purba (Ancient Danhuang Cauldron):** Kuali Alkimia Raksasa Grade 8 yang tertancap di kawah Gunung Berapi Chiyan, memanfaatkan energi teras lava langsung.
* **Perpustakaan Resep Purba (Grand Recipe Vault):** Ruang penyimpanan rahasia yang berisi ribuan gulungan resep obat purba dari Era Kuno.
* **Kebun Herbal Urat Api (Fire-Vein Herb Field):** Perkebunan khusus di lereng gunung berapi tempat menanam Bunga Teratai Api dan Ginseng Lava.
* **Artefak Pelindung - Perisai Kuali Besi Spirit:** Kuali portabel Grade 6 yang mampu menjadi benteng pelindung dari ledakan sihir.

## 6. Hubungan Diplomatik Luar, Rumor Regional & Papan Misi/Quest

### Hubungan Diplomatik
- **Perguruan Penempa Shendu (Chiyan Zhou):** Pemasok kuali spirit tempaan besi berkualitas tinggi untuk murid Danhuang.
- **Sekte Racun Youming (Youming Zhou):** Faksi musuh; Sekte Danhuang sering membongkar pemalsuan pil penyembuh bermateri racun yang dijual oleh faksi iblis.
- **Rumah Lelang Wanbao (Zhonghua Zhou):** Mitra distribusi utama pil breakthrough tingkat tinggi di seluruh benua.

### Rumor Regional yang Beredar
1. *" Master Danhuang tengah mencari herbal langka 'Rumput Jiwa Sembilan Warna' untuk meracik Pill Penembus Shenhuang."*
2. *"Di kedalaman kawah Shendu di bawah kuali purba, sering terdengar raungan Spirit Beast Api Kuno yang tersegel."*

### Papan Misi Sekte (Examples of Sect Quests)
* **Misi Harian [Tier 2]:** *Pengumpulan Bunga Teratai Api* — Petik 15 Bunga Teratai Api di lereng kawah Shendu. (Hadiah: 60 Batu Spirit + 1x Pil Energi Qi).
* **Misi Khusus [Tier 4]:** *Pengujian Kadar Racun Pil* — Uji 50 sampel pil pasar gelap dan sita produk cacat yang beracun. (Hadiah: 300 Batu Spirit + Resep Pil Antidot Grade Mid).
* **Misi Utama [Tier 6]:** *Perburuan Inti Api Spirit Kuno* — Amankan kristal inti api dari monster lava raksasa di Lembah Meteorit Merah. (Hadiah: Akses Kuali Danhuang Purba + 1.000 Reputasi Sekte).
