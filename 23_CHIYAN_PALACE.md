## 1. Lore, Sejarah Purba & Doktrin Utama

Istana Api Chiyan didirikan 9.000 tahun lalu pada akhir Era Kuno oleh **Chiyan Sovereign**, seorang kultivator pertapa legendaris yang bertapa selama 100 tahun di jantung Kawah Lava Shendu. Beliau menjadi pendekar pertama yang berhasil memperhambakan *Api Spirit Bintang Lava* tanpa membakar meridian jiwanya sendiri.

Doktrin Suci Sekte: *"Seperti Nyala Api Yang Memurnikan Logam Mentah, Kerasnya Latihan Dan Derita Lava Memurnikan Raga Menjadi Baja Abadi"*.

Istana Chiyan berdiri megah sebagai benteng batu obsidian yang langsung bertengger di atas jurang lava cair. Para murid dilatih secara ekstrem melompati pilar-pilar batu vulkanik di atas temperatur 500°C untuk membentuk ketahanan raga mutlak, kekebalan dari racun sulfur vulkanik, serta penguasaan sihir pertempuran destruktif elemen Api.

## 2. Struktur Divisi, Hirarki & Dinamika Faksi Internal

### Divisions & Halls Utama
1. **Aula Manipulasi Lava (Lava Manipulation Hall / 熔岩战殿):** Divisi tempur garis depan yang memimpin seni penyulutan gelombang lava, ombak api pembakar zirah, dan pertempuran jarak dekat berdaya ledak.
2. **Aula Penempaan Raga Api (Fire Body Tempering Hall / 炼体火火殿):** Tempat pemurnian ketahanan fisik, pembentukan otot baja, imunitas racun asap vulkanik, dan pelapisan *Raga Besi Lava*.
3. **Aula Ekstraksi Batu Meteorit (Meteorite Mining Guard Hall / 陨铁采集殿):** Bertanggung jawab mengamankan penambangan batu besi meteorit di Lembah Meteorit Merah dan Gua Lava Hitam.
4. **Balai Penghubung Youxia (Youxia Relations Pavilion / 游侠赤炎阁):** Bermitra dengan Serikat Youxia Sanxiu (`52_SERIKAT_YOUXIA_SANXIU.md`) untuk pengeluaran Misi Perburuan Monster Lava dan pengawalan karavan batu spirit.

### Dinamika Politik & Faksi Internal
- **Faksi Raga Abadi (Immortal Tempering Faction):** Dipimpin oleh Tetua Lie Yan. Menekankan bahwa kekuatan sejati berada pada kerapatan raga dan daya tahan fisik. Menolak ketergantungan berlebih pada senjata spirit.
- **Faksi Ledakan Api (Explosive Flame Faction):** Dipimpin oleh Tetua Huo Chiyan. Berfokus pada pengembangan jurus-jurus sihir area bertipe *Burst Damage* destruktif untuk menghancurkan pertahanan pasukan lawan.

## 4. Kurikulum Teknik, Syarat Masuk & Jenjang Keanggotaan

### Syarat Penerimaan & Ujian Masuk
- **Syarat Akar Spiritual:** Wajib memiliki Akar Spiritual Api (*Fire Qi*) minimal Purity 50%.
- **Ujian Berjalan Di Atas Bara (Cinder Tread Test):** Calon murid berjalan melintasi panggung batu vulkanik bersuhu 300°C di atas kawah lava tanpa mengeluh atau kehilangan kesadaran Qi.

### Jenjang Murid & Kemajuan Ranah
1. **Murid Luar (Outer Disciple):** Menambang batu bara, melatih ketahanan raga di uap vulkanik, dan menguasai *Sentuhan Api Merah*.
2. **Murid Dalam (Inner Disciple):** Bermeditasi di atas panggung lava cair, menguasai *Ombak Lava Pembakar Zirah*.
3. **Murid Inti (Core Disciple):** Menyelam ke kawah Shendu untuk mencari Inti Api Spirit dan menguasai *Akar Spiritual Api Purba Chiyan*.
4. **Murid Warisan (Legacy Disciple):** Diberi akses ke Ruang Teras Lava Chiyan dan mewarisi *Semburan Naga Lava Purba*.

### Kurikulum Teknik Warisan
- **Teknik Dasar:** *Sentuhan Api Merah (Red Flame Touch)* — Melapisi senjata dengan kobaran api untuk tambahan Fire Damage (+20%).
- **Teknik Menengah:** *Ombak Lava Pembakar Zirah (Lava Armor Breaker)* — Serangan area pembakar zirah musuh (Menghancurkan 30% Armor Defense & Burn).
- **Teknik Utama:** *Akar Spiritual Api Purba Chiyan (Chiyan Ancient Fire Law)* — Meningkatkan Damage Api +40% dan memberikan Imunitas terhadap serangan elemen api Grade 1–5.
- **Teknik Rahasia Puncak:** *Raga Besi Obsidian Lava (Obsidian Lava Body)* — Merubah kulit menjadi pelindung vulkanik yang menyerap 50% damage fisik dan memantulkan 20% Fire Damage ke penyerang jarak dekat.

## 5. Fasilitas Unik, Artefak & Sumber Daya Rahasia

* **Kawah Meditasi Api Purba (Ancient Fire Cauldron Crater):** Kawah lava alami berFormasi Penstabil Qi tempat para murid bermeditasi menyerap Qi Api murni.
* **Panggung Arena Lidah Api (Flame Tongue Arena):** Panggung batu vulkanik melayang di atas kawah lava untuk duel kehormatan sekte.
* **Gua Ekstraksi Obsidian (Obsidian Extraction Cave):** Gua bawah tanah tempat penambangan kristal api murni dan batu meteorit Grade 6.
* **Artefak Pelindung - Zirah Sisik Naga Chiyan:** Zirah Grade 7 buatan bersama Perguruan Shendu yang kebal terhadap tebasan pedang biasa dan sihir racun.

## 6. Hubungan Diplomatik Luar, Rumor Regional & Papan Misi/Quest

### Hubungan Diplomatik
- **Sekte Alkimia Danhuang (Chiyan Zhou):** Tetangga dekat & sekutu; Chiyan Palace mengamankan jalur pasokan api kawah untuk kuali Danhuang.
- **Sekte Istana Salju Abadi Hanbing (Beihan Zhou):** Rival geopolitik tradisional; sering berselisih paham mengenai perbatasan pengaruh elemen Api vs Es.
- **Serikat Youxia Sanxiu:** Pemasok utama misi perburuan monster lava dan pengawalan batu meteorit.

### Rumor Regional yang Beredar
1. *"Di dasar paling dalam Kawah Shendu, tertidur seekor Naga Lava Purba yang hanya bisa dipanggil oleh stempel Master Chiyan Sovereign."*
2. *"Ada penambang liar yang menemukan retakan ruang berisi Kristal Meteorit Bintang Merah di Lembah Meteorit."*

### Papan Misi Sekte (Examples of Sect Quests)
* **Misi Harian [Tier 2]:** *Pembersihan Kalajengking Lava* — Basmi 12 Kalajengking Lava yang mengganggu penambang batu bara di Kawah Shendu. (Hadiah: 60 Batu Spirit + 1x Batu Api Spirit).
* **Misi Khusus [Tier 4]:** *Pengawalan Karavan Meteorit* — Kawal karavan batu besi meteorit dari Lembah Meteorit Merah menuju Perguruan Penempa Shendu. (Hadiah: 300 Batu Spirit + 1x Mineral Meteorit Grade 4).
* **Misi Utama [Tier 6]:** *Penjinakan Amukan Spirit Kawah* — Selidiki dan jinakkan ketidakstabilan arus lava kawah Shendu yang mengancam pemukiman. (Hadiah: 1.200 Batu Spirit + Akses Kawah Meditasi Api Purba).
